Troubleshooting

Common Issues.

Important

Make sure to allow pasting

If you receive a security warning like "Content from the internet can be harmful, don't paste code you don't understand", simply type allow pasting into the console and press Enter.

You will then be all good to paste the loader script normally.

Protection

DevTools lock screen

The script includes built-in protection against inspecting. If Developer Tools are open, a lock overlay will appear. Close DevTools (press F12) to resume using the widget.

Reloading

Script resets on reload

Browser scripts run in the current session. Whenever you refresh or open a new tab, simply open the console and paste the loader code again to relaunch Hub Zero.
